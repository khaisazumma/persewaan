# WEXPLORE - Rental Peralatan Outdoor Surabaya

Website resmi WEXPLORE untuk rental perlengkapan outdoor premium di Surabaya.

## Tech Stack

- Astro 5
- Tailwind CSS
- TypeScript

## Commands

| Command | Action |
|:--------|:-------|
| `npm install` | Install dependencies |
| `npm run dev` | Start local dev server at `localhost:4321` |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview build locally |

## Data Source

All product, package, and settings data is fetched from Google Sheets CSV exports.
